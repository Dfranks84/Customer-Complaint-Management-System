# Project Name: Customer Complaint Management System

## Project Description
The Customer Complaint Management System is a PHP and MySQL web application designed to allow customers to submit and track complaints. The application provides separate functions for customers, technicians, and administrators. Customers can create accounts, submit complaints with images, and view complaint status and technician notes. Technicians can view assigned complaints, enter notes, and resolve complaints. Administrators can manage customers, employees, products and services, and assign complaints to technicians.

## Project Tasks
- **Task 1: Plan the application**
  - Created a project plan outlining the development tasks for each week
  - Identified customer, technician, and administrator requirements

- **Task 2: Create the database and application framework**
  - Created the MySQL database and related tables
  - Established relationships between complaint, customer, employee, product/service, and complaint type data
  - Created the PHP application structure

- **Task 3: Develop the application**
  - Implemented customer registration and account updates
  - Added complaint submission and complaint tracking
  - Created technician complaint management features
  - Created administrator management features

- **Task 4: Implement site security**
  - Added user authentication and role-based authorization
  - Protected pages based on customer, technician, and administrator access
  - Added logout and password management functionality
  - Added input validation

- **Task 5: Add file uploads and finalize the application**
  - Added image upload support for customer complaints
  - Validated uploaded image file types
  - Displayed complaint images for technicians
  - Completed final application features and database updates

- **Task 6: Test the application**
  - Tested customer registration and login
  - Tested customer account updates
  - Tested complaint creation and image uploads
  - Tested administrator management functions
  - Tested complaint assignment to technicians
  - Tested technician notes and complaint resolution
  - Tested customer viewing of complaint status and technician notes
  - Corrected issues discovered during testing
